- id (string; optional):
    Unique identifier for the component.

- key (string; optional):
    Update the component’s `key` to force it to remount.

- children (a list of or a singular dash component, string or number; optional):
    Target element for the badge. Supports components.

- className (string | dict; optional):
    CSS class name of the component. Supports [dynamic CSS classes](/advanced-classname).

- color (string; optional):
    Ribbon color.

- placement (a value equal to: 'start', 'end'; default 'end'):
    Ribbon placement. Supported values: `'start'`, `'end'`. Default: `'end'`.

- text (a list of or a singular dash component, string or number; optional):
    Ribbon content. Supports components.

- data-* (string; optional):
    Wildcard support for `data-*` attributes.

- aria-* (string; optional):
    Wildcard support for `aria-*` attributes.

- id (string; optional):
    Unique identifier for the component.

- key (string; optional):
    Update the component’s `key` to force it to remount.

- className (string | dict; optional):
    CSS class name of the component. Supports [dynamic CSS classes](/advanced-classname).

- active (boolean; default False):
    Whether to show animation. Default: `False`.

- block (boolean; default False):
    Whether to fill the parent container. Default: `False`.

- shape (a value equal to: 'circle', 'round', 'default'; default 'default'):
    Button placeholder shape. Supported values: `'circle'`, `'round'`, `'default'`. Default: `'default'`.

- size (a value equal to: 'large', 'small', 'default'; default 'default'):
    Button placeholder size. Supported values: `'large'`, `'small'`, `'default'`. Default: `'default'`.

- data-* (string; optional):
    Wildcard support for `data-*` attributes.

- aria-* (string; optional):
    Wildcard support for `aria-*` attributes.
